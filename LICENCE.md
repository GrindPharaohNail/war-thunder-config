## 🧩 About

**War Thunder Config** is a comprehensive configuration utility for War Thunder on Windows PC featuring overlay presets, keybind manager, graphics tweaks, sensitivity profiles, HUD layout editor, performance presets, and backup/restore of config files.

Based on popular community config managers and overlay tools for flight and ground battles.

---

## ✨ Features

### 🎮 Overlay & HUD
- Overlay Presets — ready-made HUD layouts for air, ground, and naval battles
- HUD Layout Editor — reposition gauges, ammo counters, and minimap markers
- Crosshair Presets — save and swap custom reticle configs
- Damage Indicator Tweaks — adjust visual feedback scale and opacity

### ⌨️ Keybinds & Controls
- Keybind Manager — import, export, and merge control profiles
- Sensitivity Profiles — per-vehicle-type aiming sensitivity presets
- Macro Layouts — multi-key sequences for flaps, gear, and armament
- Joystick Mapping — map axis curves and deadzones for flight sticks

### 🖥️ Graphics & Performance
- Graphics Tweaks — quality presets for low, medium, and high-end rigs
- Performance Presets — config bundles tuned for FPS stability
- Config Backup — snapshot and restore your settings folder
- Resolution Profiles — quick-switch between windowed and fullscreen modes
